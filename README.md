## What is this?

**Where Is My Cafe?** is a curated, aesthetic directory of the best cafés in Aurangabad. Built for the locals, by the locals. It helps you find the perfect spot based on exactly what you're looking for, whether it's a quiet place to study, a lively spot for a date, or just phenomenal coffee.

## Features

- **Mood Picker / Roulette:** Don't know where to go? Use the roulette wheel for a random recommendation, or answer a few quick questions in the Mood Picker to find your perfect match.
- **Vibe-based Searching:** Filter cafés not just by area or price, but by *vibe* (Study, Chill, Date, Party, Work).
- **Interactive Map:** View all the top spots on a sleek, interactive map of the city.
- **Detailed Profiles:** See what each place is really like—noise levels, lighting, popular items, and amenities (WiFi, AC, Parking).
- **Mobile-First Design:** A beautiful, app-like experience on your phone, with smooth interactions and micro-animations.

## Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Animations:** [Motion (Framer Motion)](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Maps:** [Leaflet](https://leafletjs.com/) & [React Leaflet](https://react-leaflet.js.org/)
- **Language:** TypeScript

## Data Structure

The café data is managed locally via JSON so the app can be served entirely as a static site. The main data file is located at:
`src/data/cafes.json`
