────────────────────────────────────────────────────────────────────────────────
  HOW TO RUN
────────────────────────────────────────────────────────────────────────────────

  Terminal 1 (API):
    cd wimc-api
    npm install        ← first time only
    npm run dev        ← starts on http://localhost:4000

  Terminal 2 (Frontend):
    cd ..
    npm run dev        ← starts on http://localhost:3000

  Test endpoints:
    http://localhost:4000/api/health
    http://localhost:4000/api/cafes
    http://localhost:4000/api/cafes/cafe-001
    http://localhost:4000/api/cafes?vibe=Study&maxPrice=300
